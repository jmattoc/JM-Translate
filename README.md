# JM-Translate

Traducción de voz bidireccional en vivo **Español ↔ Inglés** para entrevistas y reuniones técnicas (Meet, Teams, Zoom, etc.), sin que la otra parte configure nada.

- **Ellos → yo:** escucho en español (voz) y/o leo subtítulos.
- **Yo → ellos:** hablo en español y ellos me oyen en inglés (micrófono virtual).
- 100 % local, sin costo, sin guardar datos.
